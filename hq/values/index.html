Company Values

Why We Do This

Not a policy. Not a checklist for onboarding. Just the honest version of what this company is supposed to be, written down so it doesn't drift.

Vegas Sidekick exists because of a specific kind of frustration: fifteen-plus years of being told what to recommend. Concierge desks get quietly steered toward whoever pays best, not whoever's actually worth a visitor's night and money. After enough of that, the only honest move left is to build the thing that doesn't have that problem.

So this isn't a mission statement written for a wall. It's the reasoning we come back to when a call is close — when the easy recommendation and the honest one aren't the same show.

01

We'd Send a Friend, Not a Funnel

The affiliate check clears the same whether we point someone to a great show or a mediocre one. That's exactly the setup that produces bad advice everywhere else in this town — so it's the one thing we have to actively resist, on purpose, every time.

The test we actually use: if a friend flew in this weekend and asked what to see, would we say the same thing we're about to put on the page? If not, the page is wrong, not the friend.

02

Having Actually Sat in the Seat Is the Bar

A hundred-plus shows in, the difference between a recommendation and a guess is obvious from the first sentence. Guesses read like the press kit. Recommendations know which seats have a sightline problem, which nights run long, and which "family-friendly" show is really not.

We don't publish a show as a strong pick without that kind of firsthand knowledge behind it — ours or someone we trust who's actually seen it.

03

The Visitor's Night Outranks Our Revenue

Every page has to survive the same question: is this here because it helps whoever's reading, or because it helps us? When those two things point the same direction, great — that's most of the time. When they don't, the visitor wins, and we eat the smaller commission.

04

Talk Like a Local, Not a Script

Nobody trusts a recommendation that sounds like it was handed to the person saying it. We write the way you'd actually talk to someone at the bar — including the caveats, the "skip this if," and the plain acknowledgment that a show isn't for everyone.

05

Build for the Next Visit, Not the Next Click

A visitor who gets steered wrong once doesn't come back, and they tell people. The whole business only works if being right, repeatedly, is worth more than any single booking — so that's the trade we keep making.

None of this is complicated, and that's the point. It's easy to write "honest recommendations" on a homepage. It's harder to actually pick the show that pays less when it's the right call. This page exists so that decision keeps getting made the same way, even as the site grows past what one person can personally vouch for.

KrisFounder, Vegas Sidekick
