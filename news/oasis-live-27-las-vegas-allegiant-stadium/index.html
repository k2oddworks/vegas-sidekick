How Oasis Las Vegas tickets work

Fans need to register through Oasis before Thursday, September 17 at 8 a.m. PT. Successful registrants will receive a unique, non-transferable code for an allocated U.S. onsale window.

The announced U.S. onsale windows begin Friday, September 25. Registration does not guarantee a code or tickets, and the registration process is the announced public route to buy tickets.
