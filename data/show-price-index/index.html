Methodology

We record the number the seller actually publishes.

The point is reproducibility, not forcing three different checkout systems into fake precision.

01 · SNAPSHOT

One observation date

Every number in this pilot was checked on September 27, 2026. Prices can change after the observation date.

02 · PUBLIC PRICE

Use the advertised “from” price

We record the lowest explicit starting price the source publicly displays for the show. We do not calculate a lower price from a percentage-off promotion.

03 · ALL-IN PRICING

Mandatory seller fees are already included

Advertised live-event ticket prices must include mandatory seller fees. Government taxes, including Nevada’s Live Entertainment Tax (LET), may still be included in the displayed price or added separately before payment.

04 · SPECIALS

Label temporary sale pricing

If a source explicitly publishes a current sale price, we record that displayed price and label it as a sale. Mystère on Vegas.com is the example in this snapshot.

05 · STANDARD TICKETS

Skip upgrades and packages

The index is built around standard show admission. VIP packages, dining bundles and other upgrades are not used as the starting-price observation.

06 · SOURCE IT

Every number gets a link

Each observation links to the page used to capture it so writers and readers can inspect the source instead of taking our table on faith.

Don’t use this table as a guaranteed checkout quote.

A “from” price can refer to different performances or seat categories across sellers. This dataset records advertised starting prices at a specific moment. It does not claim the three sellers are offering the same seat for the same performance.
