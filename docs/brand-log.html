What it is

A static Cloudflare Pages site for discovering Las Vegas shows and booking through Spotlight.vegas affiliate links. No backend, no build step — plain HTML/CSS/JS with injected header/footer components and a client-side search.

Build log

What we've shipped

Aug 11, 2026 — the big session
2026-08-11

Cloudflare _headers — caching + security

Security headers site-wide (HSTS, nosniff, frame/referrer/permissions policy). HTML & components revalidate every load; images cached immutable for a year.

retires the ?v= cache-bust chore
2026-08-11

E-E-A-T author entity

Made /about/kris-kidd/ a canonical Person entity (ProfilePage + JSON-LD + sameAs), tied the Organization's founder to it, and linked all 20 news bylines. Corrected the bio to Kris's real story.

20 articles → 1 verifiable entity
2026-08-11

About & Kris Kidd pages reskinned

Rebuilt both on the neon design system with a real WebP portrait — and dropped ~450KB of legacy inline CSS in the process.

2026-08-11

Performance · Phase 1 — preload the hero

Added hero preload + fetchpriority="high" across every page that shows a hero image — the biggest single lever on load-time perception.

50 pages in one pass
2026-08-11

Performance · Phase 2 — de-bloat

Converted the 7 heaviest pages from base64-embedded images to real, cacheable WebP files.

222–383KB → 79–93KB per page · −1.6MB
2026-08-11

Performance · Phase 3 — modern format

Swapped JPG heroes for WebP via <picture> (JPG kept for social + cards). Resized one oversized 2500px hero from 685KB to 65KB.

23 pages · hero payload 2.3MB → 1.4MB
2026-08-11

Measured it — and stayed honest

A controlled before/after showed the real LCP win came from fixing oversized images (−36%), not from de-bloating base64. The measurement corrected the assumption.
