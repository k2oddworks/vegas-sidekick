Reference, not filler

Built for quick answers and useful citations.

The Sidekick Index is where we keep the information people ask for over and over again: who is playing, when they're here, where they're performing and the other facts that are easier to use in a clean reference than buried inside a travel article.

It's useful if you're planning a trip, but it isn't written only for tourists. Journalists, bloggers, newsletter writers, researchers, creators, locals and anyone covering Las Vegas entertainment should be able to land here, get the information they need and move on.
